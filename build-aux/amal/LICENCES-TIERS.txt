AMAL STUDIO - INVENTAIRE DES LICENCES
=====================================

Ce document recense les composants distribués avec Amal Studio pour Windows,
leur licence et leur rôle. Les textes complets des licences des bibliothèques
se trouvent dans le dossier « licences » de l'installation.

Inventaire établi le 25 octobre 2026 pour Amal Studio 1.0, à partir du code
source d'Amal Studio et des dépendances précompilées d'OBS
(obs-deps, édition 2026-07-15, commit 8683107a02300923abe4f293920f4b5edc8cb624).


1. LICENCE D'AMAL STUDIO
------------------------
Amal Studio est un logiciel libre, basé sur OBS Studio 32.2.2. Son code est
distribué sous la licence publique générale GNU (GPL), version 2 ou (au choix)
toute version ultérieure.

Le composant FFmpeg fourni avec le logiciel est compilé avec x264 sous licence
GPL version 3 (options --enable-gpl et --enable-version3). En conséquence,
l'ensemble exécutable distribué (installateur et version portable) doit être
considéré comme régi par la GPL version 3.

Conséquences pratiques :
- toute personne qui reçoit le logiciel peut l'utiliser, l'étudier, le modifier
  et le redistribuer, y compris contre paiement ;
- quiconque distribue le logiciel (gratuitement ou en le vendant) doit fournir
  le code source complet et correspondant, sous la même licence ;
- une « version Pro » distribuée sous forme de programme reste soumise à ces
  mêmes règles : son code doit être publié sous GPL.

Code source : https://github.com/amal-studio/amal-studio
