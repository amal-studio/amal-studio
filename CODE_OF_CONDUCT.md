# Code de conduite

Le projet Amal Studio adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Les participants s'engagent à rendre la participation au projet respectueuse et sans harcèlement pour tous. Les comportements inacceptables (propos insultants ou discriminatoires, harcèlement, publication d'informations privées d'autrui) peuvent être signalés à l'adresse alybako.cm@gmail.com ; chaque signalement est examiné avec discrétion.

Le code de conduite d'origine du projet OBS Studio figure dans [COC.rst](COC.rst).
